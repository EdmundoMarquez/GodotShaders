# Godot Shaders

A collection of Godot 4 projects for learning shader programming using the Godot Shading Language and Visual Shaders.

## Structure

```
GodotShaders/
└── VisualShaders/      # Godot 4.6 project — Visual Shader lessons
    ├── 01 Shader Setup/         # Introduction to shaders and the Visual Shader editor
    ├── 02 Shader Data Types/    # Scalar, vector, and matrix types in shaders
    ├── 03 UV/                   # UV coordinates and coordinate space
    ├── 04 Texture/              # Sampling and manipulating textures
    ├── 05 Shader Parameters/    # Exposing uniforms and customizing shader inputs
    ├── 06 Vertex Shader/        # Vertex shaders and vertex manipulation
    └── 07 Challenge/            # Challenge: dissolve effect
```

Each numbered folder contains a `.tscn` scene and its associated shader resources (`.tres`), serving as a self-contained lesson.

## Requirements

- **Godot 4.6+** (Forward Plus renderer)

## Getting Started

Open any project folder (e.g., `VisualShaders/`) in Godot, then open the scene for the lesson you want to explore.
